# Jev 决策分选器

## 事实与隐喻

[TypeSafe 官方文档](https://docs.typesafe.ai/introduction)定义 Jev：
输入上下文与类型化问题，返回代码可用的结构化结果。
Choice 返回选项、概率分布与置信度。
Score 返回评分、概率分布与置信度。
Noul 返回 0–1 真值。
同次请求的问题独立并行求值。
图仅演示 [Choice 意图路由](https://docs.typesafe.ai/primitives/choice)。
三个出口不是三种问题类型。
类型约束不证明业务判断永远正确。
此图不承诺延迟、准确率或价格。

卡片代表上下文。滑台对齐预设出口。
出口代表程序定义的类型化选项。
三个本地示例为 search、code、review。
固定示例不调用 Jev，不生成概率。
动画时长只服务阅读，不代表推理耗时。
一轮 0.3 秒，判断阶段 0.03 秒。
输出停留 0.0675 秒，三个出口自动轮换。

## Figure 范围

单机、60 个实体、SVG，无 WebGL。
零件由项目级 Anatomy kit 离线投影。
输入后挡板先画，再画叠卡，前挡板最后画。
三个出口的前挡板位于活动卡片之后。
相机深度决定遮挡，不以 z-index 补偿。
运行时只加载路径、纯模型和播放器。
不把 kit 或范例引入请求链。
不把静态路径构造误称为 React Server Components。

## 集成与播放

RecoveryPage 在错误说明后复用此图。
桌面双列；手机先显示恢复动作，再显示图。
图内先说明，再展示机器，最后列出出口。
viewBox 裁掉空白，不缩小文字或截断实体。
桌面双方共用三行 subgrid。
左侧主体跨两行，右侧说明与机器各占一行。
双方页脚共用第三行与相同 32px 上间距。
分割线不依赖文本长度或固定补偿像素。
404/500、noindex、查询脱敏保持原样。
图不读取目录或错误正文。
SSR 与首帧同为 search 出口的静态位姿。
减少动态效果时保持静止。
没有示例选择或播放按钮栏。
图面自身是原生按钮，点击或键盘可暂停。
悬停和聚焦不截断自动循环。
离屏、隐藏标签页暂停循环。
手动暂停只由用户恢复。
逐帧只写 SVG ref，不逐帧渲染 React。
出口说明固定展示，不逐轮播报无障碍消息。
